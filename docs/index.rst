Crew Manager Documentation
==========================

This documentation entry point covers the production ``CREW/Crew`` application.

Key references in this project:

- ``../README.md`` for setup, usage, and current testing notes
- ``../ReadMine.py`` for the production ReadMine implementation
- ``../Reading Now/README.md`` for the generated ReadMine output tree

Documentation notes
-------------------

- The production GUI and runtime code live in ``CREW/Crew/``.
- Backup and experimental copies under sibling directories such as ``xCrew`` and ``xxCrew`` are not the primary source of truth.
- ReadMine currently generates beginner-only output and prunes stale intermediate and advanced folders.
