# Crew Plan References

This directory mixes:

1. local production-facing plan notes for `CREW/Crew/`, and
2. linked design/reference artifacts maintained under `CREW/DESIGN/PLANS/`.

## Local plan files

- [code_improvement_and_testing_plan.md](code_improvement_and_testing_plan.md) - code quality and testing plan
- [crew_global_refactor_and_test_plan.md](crew_global_refactor_and_test_plan.md) - broader refactor/testing notes
- [crew_gui_enhancements_plan.md](crew_gui_enhancements_plan.md) - GUI enhancement ideas
- [crew_py_refactor_plan_2026-04-19.md](crew_py_refactor_plan_2026-04-19.md) - Crew.py refactor notes
- [crew_test_coverage_and_gaps.md](crew_test_coverage_and_gaps.md) - test-coverage observations

## Linked design artifacts

The following files resolve into `CREW/DESIGN/PLANS/` and are intended as planning
templates or reference artifacts, not runtime data files:

- `crew_template_v2.md`
- `skills_db.csv`
- `training_log.csv`

## Usage

- Use local plan markdown files here for production-adjacent notes about `CREW/Crew/`.
- Use the linked DESIGN artifacts as lightweight templates when a plan needs a role,
  skill, or training reference.
- Validate implementation details against the production app, not against old plan
  snapshots or historical exports.
